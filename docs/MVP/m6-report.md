# M6 Report: Release

Status as of 2026-10-11, branch `m6-release`, stacked on `m5-polish`. Version **1.0.0-rc.1**
(release candidate). The production deploy has not been done: it waits for your go-ahead (below).

## What's new

**Error handling** (`src/app/resilience.ts`):
- **Lost graphics context:** a WebGL context loss or WebGPU device loss pauses the game, stops the
  render loop, and shows "The graphics were reset" with a Reload button. High scores and settings
  are already saved; only the game in progress is lost. Tested by forcing a context loss
  (`WEBGL_lose_context`).
- **Renderer start-up failure:** a friendly message replaces the raw error. On WebGPU it offers
  **compatibility mode**, a reload with `?webgl` (the WebGL2 path).
- **Frame errors:** an exception in one frame is logged (the first 5) and the loop carries on. After
  30 failing frames in a row it stops with "Something went wrong" and a Reload button, instead of
  a frozen screen.
- **Audio:** if an AudioContext can't be created, the game plays silently. Resume failures are
  swallowed.
- **Storage:** already fail-safe since M5 (tested).

**How to play:** one screen, opened from the title screen ("How to play"), the pause menu, or the
address `/#how-to-play` (for linking). It covers:
- the idea, and hits with the same color, shape and label as the playfield caps (1B, 2B, 3B, HR)
- runners and rallies, outs, pitching
- B-A-T, R-U-N/STEAL, R-B-I/kickback and the skill shot
- controls for keyboard, touch and gamepad, and tilt

**Release polish:**
- **Page:** title and description meta tags, and Open Graph/Twitter share tags with absolute URLs
  (`SITE_URL`, default `https://basepinball.vercel.app`). A `noscript` message. The display font
  is preloaded.
- **Brand images**, generated by `npm run assets` (`tools/art/brand.ts`):
  - `icon.svg` (favicon)
  - `apple-touch-icon.png` and `icon-512.png`: a chrome ball with baseball stitches
  - `og.png`: a 1200×630 share card with the playfield art
- **Caching (`vercel.json`):** hashed JS and textures are cached forever. The texture manifest
  always revalidates, and fonts are cached for a week.
- **Security headers (`vercel.json`):** `nosniff`, a referrer policy, and a permissions policy
  (motion and gamepad on; camera, microphone and location off).
- **Version:** `1.0.0-rc.1+<commit>` is shown on the title screen and recorded with each high
  score.

## Name check ("Rally Ball")

A quick web search, not a legal clearance:
- **The old US trademark:** a "RALLYBALL" mark for paddle-ball equipment (class 28) was registered
  in 1991 and **cancelled in 2002**.
- **An existing game:** a mobile game called **"Rally Ball"** (a rolling-ball obstacle game by
  Quiztogether) is listed on app stores. That is the same name in the same broad market (games),
  though a different genre.
- **A similar idea:** **"Grand Slam Rally"** (86Pixels) is a pitch-and-bat pinball game for the
  Multimorphic P3. Different name, but a similar concept worth knowing about.
- **Recommendation:** before a public launch with marketing, have a proper clearance search done
  for classes 9 and 41 (software and entertainment), or keep the M3 runner-up names
  ([naming.md](naming.md)) ready.
